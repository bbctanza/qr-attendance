Kiosk Mode

Turn any laptop into a dedicated check-in station. It boots straight into the scanner, counts down to the next scheduled event, and keeps watching even when nothing is live - no one has to sit there babysitting it.

A Calmer Access Directory

The summary tiles are now filter chips that show which one is active, and the list reads as individual cards instead of a dense table on your phone.

Event Times Were Off by Hours

A 7:30 AM event could read as 11:30 PM the night before. Start times now parse correctly no matter what time zone you're in.

Password prompts stopped showing Cloudflare's "for testing only" banner - it was never a real check to begin with.
