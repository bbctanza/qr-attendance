Mobile, trigger rethought, not just re-decorated. Two passes tried to make this a better-looking button - a bordered bar, then a shadowed chip with a colored badge - and both looked out of place for the same reason: nothing else in the header is a button. The fix wasn't more polish, it was less: this is now the same plain muted metadata text the spot has always held, with the version number in brand color and a small chevron after it. It reads as the quiet line it's always been, not a new element glued on below the title. Tapping it still opens the same bottom sheet, right board.
