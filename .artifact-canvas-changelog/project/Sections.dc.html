A Kiosk, and a Quieter Password Prompt
Version 2.8.0 · November 8, 2026
New Features 1
Kiosk Mode

Turn any laptop into a dedicated check-in station. It boots straight into the scanner, counts down to the next scheduled event, and keeps watching even when nothing is live.

Improvements 2
A Calmer Access Directory

The summary tiles are now filter chips that show which one is active, and the list reads as individual cards instead of a dense table on phones.

One Password Prompt, Not a Maze

The confirmation dialog now says what it's actually confirming - "Exit kiosk mode?" instead of unrelated wording about access changes - and no longer shows a CAPTCHA test banner.

Fixes 2
Event Times Shown 8 Hours Off

A 7:30 AM event could read as 11:30 PM the night before. Start times now parse correctly regardless of time zone.

"Exit Kiosk" Did Nothing

The password prompt was opening correctly but rendering behind the kiosk screen, invisible and unreachable.

Removed 1
Test CAPTCHA on Password Prompts

It was running Cloudflare's published test key, which verified nothing and showed its own "for testing only" banner.
