v2.8.0 November 8, 2026
### Features
  • Kiosk mode. Boots a device straight into the scanner, counts down to the next event, keeps watching while idle.
### Improvements
  • Access Directory: filter chips replace the summary tiles; list rows replace the table on mobile.
  • Password-confirmation dialog now shows copy specific to what it's confirming.
### Fixes
  • Event start times parsed in the wrong time zone, off by up to 8 hours.
  • "Exit kiosk" dialog rendered behind the kiosk overlay and could not be reached.
### Removed
  • Turnstile CAPTCHA on password confirmation (was running a test-only key).
